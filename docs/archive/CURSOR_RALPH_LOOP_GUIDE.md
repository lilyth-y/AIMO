# Cursor IDE에 Ralph Loop 적용 가이드

## 개요

Ralph Loop는 Cursor IDE에서 자동으로 반복 작업을 수행하는 규칙입니다. 이미 프로젝트에 적용되어 있으며, 추가로 Self-Refine Loop 패턴도 통합했습니다.

## 현재 적용 상태

### 1. Ralph Loop 규칙 (`.cursor/rules/ralph-loop.mdc`)

**상태**: ✅ 활성화됨 (`alwaysApply: true`)

**기능**:

- 자동 작업 패턴 감지
- 완료 기준 자동 추론
- 자동 반복 실행
- 실패 시 자동 적응

**적용 시나리오**:

- 린터 에러 수정
- 테스트 실패 수정
- 리팩토링 작업
- 다중 파일 업데이트

### 2. Self-Refine Loop 패턴 (`.cursor/rules/self-refine-pattern.mdc`)

**상태**: ✅ 생성됨 (`globs: src/pipeline/**/*.py`)

**기능**:

- 코드 검증 실패 시 자동 개선
- 에러 타입별 맞춤 개선
- 최대 반복 횟수 제한
- 상태 추적 및 로깅

**적용 시나리오**:

- 검증 실패 시 코드 개선
- 테스트 실패 시 코드 수정
- 에러 타입별 개선 전략 적용

## 사용 방법

### 자동 적용

Ralph Loop는 **자동으로 적용**됩니다 (`alwaysApply: true`). 별도 설정 없이 다음 작업을 하면 자동으로 루프가 실행됩니다:

1. **에러 수정 요청**:
  ```
   "린터 에러를 수정해줘"
   "테스트를 통과시켜줘"
  ```
   → 자동으로 에러를 감지하고 수정을 반복
2. **리팩토링 요청**:
  ```
   "이 함수를 리팩토링해줘"
   "모든 파일에서 변수명을 변경해줘"
  ```
   → 자동으로 변경 사항을 적용하고 테스트
3. **코드 개선 요청**:
  ```
   "이 코드를 개선해줘"
   "검증을 통과하도록 수정해줘"
  ```
   → Self-Refine Loop 패턴 자동 적용

### 수동 트리거

특정 패턴을 명시적으로 요청할 수도 있습니다:

```
"랄프루프로 에러를 수정해줘"
"self-refine loop를 사용해서 코드를 개선해줘"
```

## 설정

### 환경 변수

Self-Refine Loop의 동작을 제어하려면 환경 변수를 설정하세요:

```bash
# 최대 반복 횟수 (기본값: 3)
export OMI_REFINE_MAX_ITERATIONS=5

# Refine 루프 활성화/비활성화
export OMI_REFINE_ENABLED=true
```

### 규칙 파일 위치

- `.cursor/rules/ralph-loop.mdc`: 일반적인 자동 반복 작업
- `.cursor/rules/self-refine-pattern.mdc`: 코드 개선 및 검증 패턴

## 작동 원리

### 1. 자동 감지

Cursor IDE가 다음을 자동으로 감지합니다:

- **작업 유형**: 에러 수정, 테스트 통과, 리팩토링 등
- **완료 기준**: 0 에러, 모든 테스트 통과 등
- **반복 필요성**: 여러 파일, 여러 에러 등

### 2. 자동 실행

```
반복 시작
  ↓
현재 상태 평가 (린터/테스트 실행)
  ↓
문제 수정
  ↓
검증 (린터/테스트 재실행)
  ↓
완료? → 예: 종료
  ↓ 아니오
다음 반복 (최대 횟수까지)
```

### 3. 자동 적응

진행이 멈추면:

1. 배치 크기 감소
2. 대안 접근법 시도
3. 문제 항목 건너뛰기
4. 3회 이상 멈추면 사용자에게 알림

## 예제

### 예제 1: 린터 에러 자동 수정

```
사용자: "린터 에러를 수정해줘"
```

**자동 동작**:

1. 린터 실행 → 에러 감지
2. 에러 수정
3. 린터 재실행 → 검증
4. 에러가 남아있으면 반복
5. 모든 에러 수정 완료 시 종료

### 예제 2: 테스트 자동 통과

```
사용자: "테스트를 통과시켜줘"
```

**자동 동작**:

1. 테스트 실행 → 실패 감지
2. 실패 원인 분석
3. 코드 수정
4. 테스트 재실행 → 검증
5. 모든 테스트 통과 시 종료

### 예제 3: Self-Refine Loop

```
사용자: "이 코드를 개선해서 검증을 통과시켜줘"
```

**자동 동작**:

1. 코드 검증 → 실패 감지
2. 에러 타입 분석 (format/arithmetic/logic)
3. RefineLoop를 사용하여 코드 개선
4. 검증 재실행
5. 최대 3회까지 반복
6. 성공 또는 최대 횟수 도달 시 종료

## 모니터링

### 진행 상황 추적

Ralph Loop는 자동으로 진행 상황을 추적합니다:

```markdown
## Progress (Auto-tracked)
Iteration: 2/15
Status: Fixing linter errors
Progress: 60%

Metrics:
- Errors: 4 → 0
- Tests: 8/10
- Files: 12/20
```

### 로깅

모든 반복 작업은 로그에 기록됩니다:

- 각 반복의 시작/종료
- 수정된 내용
- 검증 결과
- 적응 전략 변경

## 제한 사항

### 최대 반복 횟수

- **린터 에러**: 15회
- **테스트 실패**: 20회
- **리팩토링**: 25회
- **다중 파일**: 30회
- **Self-Refine**: 3-5회 (설정 가능)

### 중단 조건

다음 경우에 자동 실행이 중단됩니다:

- 완료 기준 달성
- 최대 반복 횟수 도달
- 3회 이상 진행 없음
- 사용자 명시적 중단

## 문제 해결

### 루프가 멈추지 않을 때

1. **최대 횟수 확인**: 설정된 최대 횟수를 초과하지 않는지 확인
2. **진행 상황 확인**: 실제로 개선이 이루어지고 있는지 확인
3. **수동 중단**: 필요시 명시적으로 중단 요청

### 루프가 너무 빨리 종료될 때

1. **에러 확인**: 실제로 모든 문제가 해결되었는지 확인
2. **검증 재실행**: 수동으로 검증 실행
3. **설정 조정**: 필요시 최대 반복 횟수 증가
