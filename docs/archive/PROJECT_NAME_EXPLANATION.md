# 프로젝트 이름 설명

## MathCodeOrchestrator3 프로젝트 이름의 의미

### MathCodeOrchestrator = AI Mathematical Olympiad

**MathCodeOrchestrator**는 **AI Mathematical Olympiad**의 약자로, AI가 수학 올림피아드 문제를 해결하는 능력을 평가하는 경진대회입니다.

### MathCodeOrchestrator3 = MathCodeOrchestrator Progress Prize 3

**MathCodeOrchestrator3**는 **MathCodeOrchestrator Progress Prize 3**를 의미합니다:
- **Progress Prize**: 진행상 상 (대회가 진행되면서 성과를 보여주는 팀에게 주는 상)
- **3**: 3회 대회

### 대회 버전

MathCodeOrchestrator는 여러 버전이 있습니다:

1. **MathCodeOrchestrator 1** (또는 MathCodeOrchestrator Progress Prize 1)
   - 첫 번째 대회
   - AIME 수준의 문제
   - 우승팀: NuminaMath

2. **MathCodeOrchestrator 2** (또는 MathCodeOrchestrator Progress Prize 2)
   - 두 번째 대회
   - AIME/국가 올림피아드 수준
   - 규칙 정립 및 시스템화

3. **MathCodeOrchestrator 3** (또는 MathCodeOrchestrator Progress Prize 3) ← **현재 프로젝트**
   - 세 번째 대회
   - **IMO (국제수학올림피아드) 수준** 포함
   - 최고 난이도
   - 5자리 정수 정답 (0-99,999)
   - H100/L4 GPU 제공

## 왜 "MathCodeOrchestrator3"인가?

프로젝트 디렉토리 이름이 `MathCodeOrchestrator3_Project`인 이유:
- 이 프로젝트는 **MathCodeOrchestrator Progress Prize 3** 참가를 위한 것입니다
- MathCodeOrchestrator 1, 2와 구분하기 위해 "3"을 명시했습니다
- 리포트에서도 "MathCodeOrchestrator 3"로 명시되어 있습니다
