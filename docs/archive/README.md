# docs/archive

이 폴더에는 **과거 완료 작업 요약**, **시점 종속 리포트**, **이전 계획 문서**가 들어 있습니다.  
**현재 기준 문서**는 상위 폴더의 [docs/README.md](../README.md) 인덱스를 참고하세요.

## 포함된 문서 유형

- P0/개선 완료 요약 (P0_*)
- 정리·클린업 요약 (CLEANUP_*, cleanup_plan 등)
- 기능 완료 리포트 (REFINE_LOOP_INTEGRATION_*, EXECUTION_RESOURCE_LIMITS_COMPLETE 등)
- 개선 로드맵·진행 (IMPROVEMENT_*)
- PD 프로젝트 (PD_*)
- 프로젝트 이름/구성 논의 (NAME_*, PROJECT_NAME 등)
- 계획·리뷰 (Plan_Review, Development_Plan, PROJECT_STATUS 등)
- 평가 리포트 시점 스냅샷 (evaluation_*, COMPREHENSIVE_*, Report.md 등)
- 기타 참고용 (MATHEMATICAL_SOLUTION_RESEARCH_TREE, DOCKER_STATUS, PROJECT_STRUCTURE.md 등)
- 문서–코드 동기화 요약 (DOC_CODE_SYNC_*.md)

필요할 때만 참고하고, 새 작업은 **docs/** 루트의 살아 있는 문서를 기준으로 하면 됩니다.
