# AIMO 프로젝트 소개 (로우 레벨)

---

## 1. 한 문장으로 말하면

**“수학 문제 문장을 넣으면, 컴퓨터가 단계를 나눠 생각하고, 필요한 계산을 코드로 실행해서 답을 구해 주는 시스템”** 입니다.

---

## 2. 왜 필요한가요?

- 시험·과제에는 **수학 문제**가 있고, 사람이 풀면 시간이 오래 걸립니다.
- **AIMO**는 그 문제 문장을 프로그램에 넣으면, 프로그램이 **스스로 단계를 나누고**, **계산을 수행**해서 **최종 답**을 내놓도록 만든 것입니다.
- “인공지능이 수학 문제를 푼다”고 생각하면 됩니다. (실제로는 큰 언어 모델과 코드 실행을 조합한 시스템입니다.)

---

## 3. 뭘 넣고 뭘 나오나요?

- **넣는 것**: 수학 문제가 적힌 **글(텍스트)**. 예: “방정식 2x + 3 = 7을 만족하는 x를 구하시오.”
- **나오는 것**: **숫자나 식 형태의 답**. 예: “2” 또는 “x = 2”.

문제가 복잡하면, **중간에 어떤 단계로 생각했는지**도 같이 볼 수 있도록 되어 있습니다.

---

## 4. 어떻게 푸나요? (이해만 하면 되는 수준)

큰 흐름만 보면 다음과 같습니다.

1. **문제 읽기**  
   프로그램이 문제 문장을 읽고, “이건 방정식 문제다”, “이건 기하 문제다”처럼 **종류를 나눕니다.**

2. **전략 정하기**  
   그 종류에 맞춰 “직접 계산할지”, “그래프를 그려볼지”, “공식을 쓸지” 같은 **풀이 방식을 정합니다.**

3. **실제 계산하기**  
   정한 방식에 따라 **작은 프로그램(코드)**을 만들어서, 그 코드를 **실행**해 숫자나 식을 구합니다.

4. **답 맞는지 확인하기**  
   나온 결과가 말이 되는지 **한 번 더 검사**하고, 문제에서 요구한 형식(예: `\boxed{2}`)으로 **최종 답**을 냅니다.

이걸 **“5단계 파이프라인”** 이라고 부르고, 각 단계가 순서대로 돌아가면서 문제를 풉니다.

---

## 5. “파인튜닝”이 뭔가요?

- 프로그램 안에는 **미리 학습된 “수학·추론” 모델**이 들어 있습니다.
- **파인튜닝**이란: 그 모델을 **우리 프로젝트에서 쓰는 문제 스타일·형식**에 더 맞게 **한 번 더 학습**시키는 작업입니다.
- 그래서 “우리 방식으로 풀고, 우리 형식으로 답을 내는” 데 더 잘 맞게 만드는 단계라고 보면 됩니다.

---

## 6. “대시보드”는 뭔가요?

- **대시보드**는 **웹 페이지 하나**라고 생각하면 됩니다.
- 그 안에서:
  - 이 시스템이 **어떤 단계로 동작하는지**,
  - **몇 개 맞혔는지(정확도)**,
  - **각 문제를 어떻게 풀었는지(풀이 과정)**  
  를 **그래프와 표**로 보여 줍니다.
- 발표하거나 결과를 점검할 때 쓰는 **화면**입니다.

---

## 7. 정리

| 말 | 의미 (쉽게) |
|----|-------------|
| **AIMO** | 수학 문제 문장을 넣으면, 단계를 나눠 생각하고 코드로 계산해서 답을 내는 시스템 |
| **5단계 파이프라인** | 문제 분류 → 전략 선택 → 코드 생성·실행 → 검증 → 최종 답 |
| **파인튜닝** | 이미 있는 “수학 모델”을 우리 문제 스타일에 맞게 한 번 더 학습시키는 것 |
| **대시보드** | 정확도, 풀이 과정, 파이프라인을 보여 주는 웹 화면 |

수학이나 AI 용어를 몰라도, **“문제 텍스트 넣기 → 단계별로 풀기 → 답 나오기”** 라는 그림만 잡으면 이 프로젝트의 목적을 이해하실 수 있습니다.
