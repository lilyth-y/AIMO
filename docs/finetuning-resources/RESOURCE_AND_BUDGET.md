# AIMO 추가 재원 조사

**목적**: 현재 프로젝트를 수행·확장하는 데 **추가로 필요한 재원(인력·하드웨어·비용·데이터)** 이 있는지 조사하고, 필요 시 어떤 것을 우선할지 정리합니다.

---

## 1. 현재 갖춰진 것 (추가 비용 없이 사용 가능)

| 항목 | 내용 |
|------|------|
| **소스 코드** | 5단계 파이프라인, 평가 유틸, 대시보드, Kaggle 연동 등 전체 코드베이스 |
| **오픈 데이터** | NuminaMath-1.5 (HuggingFace), AIME 검증셋, 프로젝트 내 60문항 균형 평가셋 |
| **학습/평가 스크립트** | `run_numina_evaluation.py`, `train_qlora.py` 등. 로컬/Kaggle/Colab에서 실행 가능 |
| **문서** | 파인튜닝 가이드, 프로젝트 구조·순서, 로우/하이 레벨 소개, 외부 컴퓨팅 옵션 등 |
| **CI** | GitHub Actions (테스트, 선택적 평가 아티팩트). 기본 러너는 GPU 없음 |
| **대시보드** | Vite+React 기반 정적 앱. 호스팅 비용 없이 로컬 또는 정적 배포 가능 |

**결론**: **코드·데이터·문서·기본 CI·대시보드**는 이미 있어서, “추가 재원 없이” 로컬/무료 클라우드만으로 평가·실험·발표는 가능합니다.

---

## 2. 추가로 필요할 수 있는 재원

### 2.1 GPU / 컴퓨팅

| 상황 | 필요 재원 | 비고 |
|------|-----------|------|
| **로컬에 GPU 없음** | 클라우드 GPU 또는 원격 추론 API | 평가·파인튜닝 시 필요 |
| **파인튜닝 (QLoRA 1.5B)** | 약 16GB VRAM 권장 (T4 16GB, Colab Pro 등) | Kaggle/Colab 무료 티어로 가능하나 시간·세션 제한 있음 |
| **큰 모델 (7B·32B) 추론** | 24GB~80GB VRAM (L4, A100, H100 등) | MathCodeOrchestrator 3 제공 GPU 또는 클라우드 임대 |
| **CI에서 GPU 평가** | Self-hosted GPU 러너 또는 GPU 클라우드 잡 | 선택 사항. 없으면 로컬/수동 실행으로 대체 가능 |

- **무료 활용**: Kaggle 주당 GPU 시간, Google Colab 무료 GPU (세션 제한).  
- **유료**: AWS/GCP/Azure GPU 인스턴스, Lambda Labs, RunPod, 또는 HuggingFace/Replicate/Together 등 **추론 API** (사용량 기준 과금).

**추가 재원 필요 여부**:  
- **로컬 GPU 있음 (8GB 이상)** → 소규모 평가·1.5B 파인튜닝은 추가 재원 없이 가능.  
- **로컬 GPU 없음** → 무료(Kaggle/Colab)로 제한적 진행 가능; **안정적·대량 실험**을 원하면 **클라우드 GPU 또는 추론 API 예산**이 필요.

---

### 2.2 데이터·라이선스

| 항목 | 상태 | 추가 재원 |
|------|------|-----------|
| **NuminaMath-1.5** | HuggingFace 공개 데이터셋 | 없음 |
| **AIME/검증셋** | 프로젝트 내 사용·문서 기준 공개/교육용 | 없음 (재배포 시 라이선스 확인 권장) |
| **자체 수집·라벨링** | 고품질 추가 데이터가 필요할 때 | 인력·시간 또는 라벨링 비용 |
| **상용 데이터셋** | 별도 구매 시 | 라이선스 비용 |

**결론**: **현재 사용 중인 오픈 데이터만으로는 추가 재원 불필요**. 대회 상위권·맞춤 도메인을 노리면 자체 데이터 구축·구매 시에만 비용이 발생합니다.

---

### 2.3 서비스·도구 (선택)

| 서비스 | 용도 | 추가 재원 |
|--------|------|-----------|
| **Weights & Biases (W&B)** | 파인튜닝 로그·실험 관리 | 무료 티어 있음. 팀/대량 사용 시 유료 |
| **HuggingFace Inference API** | GPU 없이 추론 | 무료 할당량 있음. 초과 시 과금 |
| **Replicate / Together 등** | 원격 추론 | 사용량 기준 과금 |
| **도메인·호스팅** | 대시보드 공개 URL | 선택. GitHub Pages 등 무료 가능 |

**결론**: **필수 아님**. 무료 티어와 오픈 도구만으로 진행 가능; 편의·규모 확장 시에만 유료 서비스 검토하면 됩니다.

---

### 2.4 인력·시간

| 활동 | 추가 재원 |
|------|-----------|
| **버그 수정·기능 추가** | 개발 인력·시간 |
| **파인튜닝 실험·하이퍼파라미터 탐색** | 실험 시간·GPU 시간 |
| **대회 제출·리포트 작성** | 참가자 인력·시간 |
| **데이터 라벨링·검수** | 인력 또는 아웃소싱 비용 |

**결론**: **“재원”이라기보다 일정·역할 배분** 이슈. 예산으로 “GPU 시간”이나 “라벨링 비용”을 구매할 수는 있음.

## 3. 시나리오별 정리

| 시나리오 | 추가 재원 필요 여부 | 비고 |
|----------|---------------------|------|
| **로컬에서 소규모 평가·데모** | **아니오** | 로컬 GPU 8GB+ 또는 CPU로 소량 평가 |
| **Numina 60문항 전체 평가 (1.5B)** | **아니오** (GPU 있음) / **예** (GPU 없음) | GPU 없으면 Kaggle/Colab 무료 또는 API/클라우드 |
| **QLoRA 파인튜닝 (5만 샘플)** | **아니오** (Kaggle/Colab 활용) | 세션·시간 제한 내에서 가능. 빠른 반복을 원하면 유료 GPU |
| **7B·32B 모델 추론·학습** | **예** | 대회 제공 GPU 또는 클라우드 GPU/API 예산 |
| **CI에서 매번 GPU 평가** | **예** (GPU 러너) | Self-hosted GPU 또는 클라우드 잡. 없으면 수동 평가 |
| **대시보드·문서만 공유** | **아니오** | 무료 호스팅·저장소로 충분 |

---

## 4. 결론 및 권장 사항

- **추가 재원이 “반드시” 필요한 경우**  
  - **로컬 GPU가 전혀 없고**, Kaggle/Colab만으로는 부족할 때 → **클라우드 GPU 또는 추론 API 예산**.  
  - **7B 이상 모델**을 쓰거나 **대회 규모 실험**을 할 때 → **대회 제공 GPU** 또는 **클라우드/API 예산**.  
  - **자체 데이터 구축·구매**를 할 때 → **데이터·라벨링 비용**.

- **추가 재원 없이 가능한 것**  
  - 현재 코드·데이터로 **평가·파인튜닝·대시보드·문서화**까지 진행.  
  - **1.5B QLoRA**는 Kaggle/Colab 무료 티어로 실행 가능 (시간 제한은 있음).  
  - **원격 추론**은 `OMI_REMOTE_INFERENCE_URL`로 연동 가능하며, 무료 할당량 있는 API로도 테스트 가능.

- **우선순위 제안**  
  1. **없어도 됨**: 별도 인력 채용·상용 데이터 구매 (당장은 오픈 데이터로 충분).  
  2. **있으면 유리**: 로컬 또는 무료 클라우드 GPU (8GB 이상) — 평가·파인튜닝 반복용.  
  3. **목표에 따라**: 대회 상위권·대형 모델을 노리면 **GPU/클라우드 또는 추론 API 예산**을 계획하는 것이 좋습니다.

이 문서는 **현재 시점**의 코드·문서·환경을 기준으로 한 조사입니다. 대회 규정·새 데이터·새 인프라가 바뀌면 재검토하는 것을 권장합니다.
