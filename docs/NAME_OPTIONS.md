# 프로젝트 이름 옵션

## 선택된 이름: OMI

**OMI** = **Orchestrated Math Interpreter**

### 의미
- **Orchestrated**: 오케스트레이션된 (체계적으로 조율되는)
- **Math**: 수학
- **Interpreter**: 인터프리터 (코드 해석 및 실행)

### 핵심 메시지
- Math Orchestration ✅
- Code Interpreter ✅

## 대안: OMNU 아이디어

### 옵션 1: Orchestrated Math & Neural Unit
- **의미**: 오케스트레이션된 수학 및 신경망 유닛
- **약자**: OMNU
- **특징**: Neural Network 강조

### 옵션 2: Orchestrated Math Neural Utility
- **의미**: 오케스트레이션된 수학 신경망 유틸리티
- **약자**: OMNU
- **특징**: 유틸리티/도구 성격 강조

### 옵션 3: Orchestrated Math Neural Understanding
- **의미**: 오케스트레이션된 수학 신경망 이해
- **약자**: OMNU
- **특징**: 이해/추론 능력 강조

### 옵션 4: Orchestrated Math Neural Unifier
- **의미**: 오케스트레이션된 수학 신경망 통합기
- **약자**: OMNU
- **특징**: 통합/조율 기능 강조

## 추천

**OMI (Orchestrated Math Interpreter)** 추천:
- 간결하고 명확함
- Math Orchestration + Code Interpreter 두 개념 모두 포함
- 발음하기 쉬움
- 전문적이면서도 기억하기 쉬움

OMNU는 더 복잡하지만, Neural Network를 강조하고 싶다면 좋은 선택입니다.
