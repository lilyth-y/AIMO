# 프로젝트 이름 제안

## 요구사항
- "math orchestration" (수학 오케스트레이션)
- "code interpreter" (코드 인터프리터)

## 이름 후보

### 옵션 1: MathCodeOrchestrator
- **의미**: 수학 문제를 코드로 해석하고 오케스트레이션
- **약자**: MCO
- **장점**: 명확하고 직관적

### 옵션 2: OrchestratedMathInterpreter
- **의미**: 오케스트레이션된 수학 인터프리터
- **약자**: OMI
- **장점**: 두 개념을 모두 포함

### 옵션 3: MathOrchestrator
- **의미**: 수학 오케스트레이터
- **약자**: MO
- **장점**: 간결함

### 옵션 4: CodeMathOrchestrator
- **의미**: 코드 기반 수학 오케스트레이터
- **약자**: CMO
- **장점**: 코드 인터프리터 강조

### 옵션 5: MathInterpreter (간단한 버전)
- **의미**: 수학 인터프리터
- **약자**: MI
- **장점**: 매우 간결

### 옵션 6: OrchestratedCodeMath
- **의미**: 오케스트레이션된 코드 수학
- **약자**: OCM
- **장점**: 모든 요소 포함

## 추천

**MathCodeOrchestrator (MCO)** 또는 **OrchestratedMathInterpreter (OMI)**

두 개념을 모두 잘 표현하면서도 전문적입니다.
